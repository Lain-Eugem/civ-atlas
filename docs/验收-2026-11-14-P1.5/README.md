# 开局设置面板 UX 重构（P1.5，task-24）

对应反馈：用户 m05027 的 5 条体验问题（国家数量/州数滑条冗余、点名单不选中不飞首都、删建国家地图不实时刷新、
国家名单与君主定制各有一个「新建国家」且应用后不能改/不能命名、随机小国飞地无机制）。

## 改了什么

### 1. 面板结构：一块面板、两个区，删掉冗余控件
- 顶部统计行取代「国家数量」滑条：`共 N 国 · AI x · 程序 y · 你 n`（数量由名单本身决定，可增删）。
- 君王定制区删掉「初始州数」滑条与「＋新建国家（在地图上点选）」下拉——疆域只在 ① 国家区或「在地图上选疆域」里确定。
- 国家区行内：名称 / 州数 / 控制方式（AI 君主 / 程序）/ ✎ 改名 / ✕ 删除；点行=扮演并飞首都。

### 2. 实时生效（核心重写）
- `mcp/viewer/start-custom.js` 全量重写（1114 行）：不再做本地预览+一次性应用，任何编辑（删国/改控制/改名/新建/地图选疆域/角色卡字段）
  debounce 180ms 直接调 `POST /api/session/start-setup`（角色卡走 `custom-start`），成功后用返回 `state` 刷新地图与右栏并重填面板。
- 失败 toast + 回滚重载；最后一州删除返回 409 needConfirm，面板内联确认；保存中按钮禁用显示「保存中…」。
- 「应用开局」按钮改名「完成」，只关闭面板；第 1 回合前可反复修改。

### 3. 点名单行 = 选中 + 高亮 + 飞首都
- 点行（非按钮）→ 选中为玩家国、行高亮、地图高亮该国全部州（暖橙半透明）、`CivMap.flyTo` 到首都居中
  （≤10 州 260% / ≤40 州 180% / 更大 150%，520ms 缓动）；同一行再点取消。
- `mcp/viewer/region-picker.js` 新增 `preview(pid)/clearPreview()`：只叠加高亮层，不接管指针、不进入点州模式。

### 4. 新建国家唯一入口 + 命名
- 国家名单底部内联表单：名称（可空＝自动）/ 🎲自动命名 / 州数 3–40 / 控制方式 / 落点（自动或地图点选）/【＋创建国家】。
- 空名自动用中文国名生成规则（赤/苍/玄/景/澜/朔 + 山/川/陵/原/海 + 部/国/王朝/汗国/城邦），自动去重。
- 创建即入名单并选中；行内 ✎ 可改名（存 `s.startSetup.names`）。

### 5. 飞地最小守卫（不做完整机制）
- `mcp/monarch-start.ts` 新增 `largestConnectedSubset`（用 `civ.regions.adjStart/adj` BFS），`applyCustomStart` 的 `regionIds`
  默认裁剪到最大连通块，返回 `droppedRegions`，面板提示「已忽略 N 个不连通的州(勾选「允许飞地」可保留)」。
- 表单与选疆域区提供「允许飞地」开关（默认关）；后续可再加行内「清理飞地」，完整飞地机制留待以后。

## API / 服务端变更
- `POST /api/session/start-setup`：可反复调用且幂等；新增 `names`、`playerPolityId`（0 表示取消扮演）、`cleanExclaves`、`allowExclaves`。
- `GET /api/start/auto-name`：按当前名单返回不重复自动国名。
- `startConfigStatus` 增 `playerPolityId`、`customStart`、每国 `regionIds`。
- `custom-start` 允许切换目标国；`regionIds` 默认裁剪连通性；`applyCustomStart` 写回 `s.startSetup`。

## 已知限制
1. 引擎第一回合会按全图规则重算新建国的国名与颜色，自定义名只存 `s.startSetup.names`（回合前名单/面板可见，回合后可能变）。
2. 飞地只做了「新建/选疆域默认保留最大连通块 + 允许飞地开关」；引擎随机生成国家的既有飞地未自动整理，完整飞地机制以后再做。
3. 实时保存是破坏性的（改即生效），目前没有「撤销上一次操作」；需要回到初始名单只能重新创建会话。
4. preview 高亮是客户端叠加，不参与服务端状态；面板关闭后自动清除。
