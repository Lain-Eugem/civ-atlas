# 验收：P4.5 去掉"玩家国家"概念（m05242 修正）

## 背景与修正

用户 m05242：「这个"自己"的国家是什么意思,我从来没有让玩家也去操作一个国家啊?」

- 原设计（P4）错误地把 DM 硬命令绑定在"玩家自己的国家"上：没有在开局设置里选国家时，DM 对话框提示「还没选自己的国家: 先在「开局设置」里选国家, 再下命令」。
- 用户对 DM 的定位是**上帝 / 裁定者视角**：可以直接对任意国家下硬命令（用户原话示例：「X 国立刻对 Y 国开战」）。不存在"玩家操作一个国家"的设定。
- 本次修正：去掉全部"玩家 / 扮演 / 你 / 自己的国家"概念；DM 命令必须**显式点名国家**；开局设置面板中"点行"的含义改为"选中该国（用于编辑君主 / 疆域）"。

## 改动（9 个文件）

- `mcp/player-commands.ts`：解析器重写为上帝视角，不再依赖 playerPolityId/mine；命令必须点名国家（全名 / 去后缀简称 / `P<编号>`）。
  - 两方命令：`让 A 对 B 开战`、`A 与 B 结盟`、`让 A 渗透 B`、`让 A 灭掉 X` 等；
  - 单国命令：`让 A 停止扩张 / 扩张 / 通商 / 发展 / 坚持打 / 中立 / 防守`；
  - 点名不足时 ok:false 并给出两方示例。
- `mcp/viewer.ts`：`POST /api/dm/chat` 不再取 `mine`（不再要求 playerPolityId）；custom-start 不再写 `s.playerPolityId`。
- `mcp/viewer/dm-chat.js`：删除「还没选自己的国家…」提示与 `.dmc-warn`；占位与命令示例改为上帝视角。
- `mcp/viewer/start-custom.js`：统计行去掉「· 你 n」；行点击 =「选中该国（用于编辑君主/疆域）」+「· 已选」标记；②标题改「君主定制（所选国家：X）」；删 `pending.playerPolityId`。
- `mcp/viewer/app.js`：删除 `playerPolityName` 传参；「玩家/DM」→「DM/复核者」两处文案。
- `mcp/engine.ts`、`mcp/monarch-start.ts`：仅注释/文案中性化，逻辑不变（引擎内 `playerCommands` 字段名保留，语义改为"用户(DM)命令队列"）。
- `docs/验收-2026-11-14-P4/README.md`、`docs/验收-2026-11-14-P1.5/README.md`：加本次修正说明。

## 已知限制

1. 国名匹配支持全名、去后缀简称、`P<编号>`，未做任意子串模糊匹配（避免误匹配）。
2. `stateView` 仍返回历史遗留字段 `playerPolityId/playerPolityName`（值可为 null，UI 不展示）。
3. 命令队列内部字段仍叫 `playerCommands`（引擎层命名沿用），语义已改为"用户(DM)命令队列"。
4. 「灭掉 X」默认把 X 的州散成无主；「让 A 灭掉 X」把 X 并入 A。
